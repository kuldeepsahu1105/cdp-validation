[NOTE]

*Data Generation:* Spark TPC-DS uses its own data generation pipeline (`spark-tpcds-datagen`). Unlike Impala and Trino, which can reuse Hive-generated data, Spark generates data independently into HDFS via a dedicated Spark job.

== Prerequisites

=== Kerberos Authentication
Authenticate as the `hdfs` user to create core directories and manage HDFS permissions:

[source,bash]
----
kinit hdfs@YOUR.REALM
----

=== Create Required HDFS Directories
[source,bash]
----
hdfs dfs -mkdir -p /user/systest/spark-sql-perf
hdfs dfs -mkdir -p /data/tpcds
hdfs dfs -mkdir -p /datasets/tpcds/queries
hdfs dfs -mkdir -p /tmp/metrics
hdfs dfs -chmod 777 /data/tpcds
----

== Upload Artifacts to HDFS

=== Upload JARs and Configurations
[source,bash]
----
cd spark-tpcds
# Path to hive-site.xml on CDP Base:
# /etc/hive/conf.cloudera.hive_on_tez/hive-site.xml

hdfs dfs -put /etc/hive/conf.cloudera.hive_on_tez/hive-site.xml /user/systest/spark-sql-perf/
hdfs dfs -put spark-tpcds-datagen*.jar /user/systest/spark-sql-perf/
hdfs dfs -put spark-query-executor*.jar /user/systest/spark-sql-perf/
----

=== Upload TPC-DS Query Files
[source,bash]
----
hdfs dfs -put queries/*.sql /datasets/tpcds/queries/
----

== Distribute TPC-DS Tools to All Worker Nodes
The `dsdgen` binary must be present on every worker node because Spark executors perform data generation locally.

[source,bash]
----
cp -r tools /tmp/
chmod -R 777 /tmp/tools

for host in pvcbase-worker1 pvcbase-worker2 pvcbase-worker3; do
  echo "=== $host ==="
  scp -r /root/tpc/tpcds-cloudera/tools/tools $host:/tmp/
  ssh $host "chmod -R 777 /tmp/tools"
done
----

== Generate TPC-DS Data via Spark
`kinit` as the `hive` user before submitting the Spark job.

[source,bash]
----
kinit hive@YOUR.REALM

spark3-submit \
  --master yarn \
  --deploy-mode cluster \
  --files hdfs://pvcbase-master.cldrsetup.local:8020/user/systest/spark-sql-perf/hive-site.xml \
  --num-executors 5 \
  --executor-cores 2 \
  --executor-memory 3G \
  --driver-memory 3G \
  --driver-cores 2 \
  --queue default \
  --class com.databricks.spark.sql.perf.TPCDSDataGen \
  --conf spark.locality.wait=0s \
  hdfs://pvcbase-master.cldrsetup.local:8020/user/systest/spark-sql-perf/spark-tpcds-datagen-3.2.0.2.12.jar \
  --path "/data/tpcds" \
  -s 10 \
  --skipDatagen false \
  --toolsDir /tmp/tools
----

== Run TPC-DS Queries

=== Option A — Run a Subset of Queries (Testing)
[source,bash]
----
spark3-submit \
  --master yarn \
  --deploy-mode cluster \
  --num-executors 5 \
  --executor-cores 2 \
  --executor-memory 3G \
  --driver-memory 3G \
  --driver-cores 1 \
  --queue default \
  --class org.hw.qe.hcube.BatchSparkSQLExecutor \
  --files hdfs://pvcbase-master.cldrsetup.local:8020/user/systest/spark-sql-perf/hive-site.xml \
  --conf spark.dynamicAllocation.enabled=false \
  --conf spark.dynamicAllocation.shuffleTracking.enabled=false \
  --conf spark.locality.wait=0s \
  --conf spark.kerberos.access.hadoopFileSystems=hdfs://pvcbase-master.cldrsetup.local:8020/ \
  --conf spark.sql.optimizer.dynamicPartitionPruning.enabled=true \
  --conf spark.driver.memoryOverhead=512m \
  --conf spark.executor.memoryOverhead=512m \
  hdfs://pvcbase-master.cldrsetup.local:8020/user/systest/spark-sql-perf/spark-query-executor-3.4.1-1.0.jar \
  --hdfs hdfs://pvcbase-master.cldrsetup.local:8020/tmp \
  --path hdfs://pvcbase-master.cldrsetup.local:8020/datasets/tpcds/queries \
  --metricsPath hdfs://pvcbase-master.cldrsetup.local:8020/tmp/metrics/ \
  --metricsFs HDFS \
  --database dex_tpcds_sf10_withdecimal_withdate_withnulls \
  --sequential \
  --iterations 1 \
  --warmupIterations 0 \
  -q query32 -q query79 -q query90
----

=== Option B — Run All 99 TPC-DS Queries
[source,bash]
----
# Run all queries. Note that queries 14, 23, 24, and 39 have 'a' and 'b' variants.

----

== Collect and View Query Metrics

=== Download and Parse Metrics
[source,bash]
----
hdfs dfs -get /tmp/metrics /tmp/metrics
cd /tmp/metrics/
chmod +x collect_query_exec_time.py
python3 collect_query_exec_time.py /tmp/metrics/ /tmp/metrics/output/
----

=== View Sorted Results
[source,bash]
----
cd /tmp/metrics/output/
(head -1 default.csv; tail -n +2 default.csv | grep -v "Query_Name" | sort -V)
----

== Run via CDE (Cloudera Data Engineering)
This is an optional method using the CDE CLI.

=== Create the CDE Job
[source,bash]
----
./cde job create \
  --name tpcds-benchmark-run \
  --type spark \
  --tls-insecure \
  --application-file hdfs://pvcbase-master.cldrsetup.local:8020/user/systest/spark-sql-perf/spark-query-executor-3.4.1-1.0.jar \
  --class org.hw.qe.hcube.BatchSparkSQLExecutor \
  --executor-cores 4 \
  --executor-memory 12G \
  --num-executors 8 \
  --driver-memory 8G \
  --driver-cores 2 \
  --conf spark.kerberos.access.hadoopFileSystems=hdfs://pvcbase-master.cldrsetup.local:8020/ \
  --files hdfs://pvcbase-master.cldrsetup.local:8020/user/systest/spark-sql-perf/hive-site.xml
----

=== Run All Queries via CDE (Shell Expansion)
[source,bash]
----
./cde job run --name tpcds-benchmark-run --tls-insecure \
  --arg "--hdfs" --arg "hdfs://pvcbase-master.cldrsetup.local:8020/tmp" \
  --arg "--path" --arg "hdfs://pvcbase-master.cldrsetup.local:8020/datasets/tpcds/queries" \
  --arg "--database" --arg "dex_tpcds_sf100_withdecimal_withdate_withnulls" \
  --arg "--metricsPath" --arg "hdfs://pvcbase-master.cldrsetup.local:8020/tmp/metrics/" \
  --arg "--metricsFs" --arg "HDFS" \
  --arg "--sequential" \
  --arg "--iterations" --arg "1" \
  --arg "--warmupIterations" --arg "0" \
  $(for i in $(seq 1 99); do
    case $i in
      14|23|24|39) echo --arg "-q=query${i}a" --arg "-q=query${i}b" ;;
      *)           echo --arg "-q=query$i" ;;
    esac
  done)
----

== Quick Reference Summary
[cols="1,2,3", options="header"]
|===
| Step | Action | Purpose
| 1 | `hdfs dfs -put` | Stage JARs and queries in HDFS
| 2 | `scp tools` | Distribute binaries to worker nodes
| 3 | `spark3-submit` (DataGen) | Generate raw data in HDFS
| 4 | `spark3-submit` (Executor) | Run benchmark queries
| 5 | `python3 collect...` | Aggregate execution times
| 6 | `cde job run` | (Optional) Execute via CDE CLI
|===
