*Data Reuse:* If you have already generated TPC-DS data as part of the Hive benchmark, the same data can be reused for Impala. Simply point Impala to the existing HDFS location (e.g., `/tmp/TPC-DS/Hive/100`).

== Prerequisites

Authenticate with Kerberos before running any Impala commands.

* **Base Cluster:** `kinit` as the Hive or service user.
* **Impala Virtual Warehouse:** `kinit` using your personal username.

[source,bash]
----
kinit your_username@YOUR.REALM
----

== Create External Tables
This step creates Impala external tables that point to the already-generated TPC-DS data residing on HDFS.

[source,bash]
----
impala-shell -V -k --ssl \
  -i pvcbase-worker2.cldrsetup.local:21050 \
  --var=scale=100 \
  --var=location=/tmp/TPC-DS/Hive/100 \
  -f scripts/impala-external.sql
----

== Create Parquet Tables
Define the optimized Parquet-format tables within the Impala catalog:

[source,bash]
----
impala-shell -V -k --ssl \
  -i pvcbase-worker2.cldrsetup.local:21050 \
  --var=scale=100 \
  -f scripts/impala-parquet.sql
----

== Insert Data into Parquet Tables
Populate the optimized Parquet tables by selecting data from the external tables created in the previous step:

[source,bash]
----
impala-shell -V -k --ssl \
  -i pvcbase-worker2.cldrsetup.local:21050 \
  --var=scale=100 \
  -f scripts/impala-insert.sql
----

== Compute Statistics
This step is **critical** for performance. It computes table and column statistics used by the Impala query planner.

[source,bash]
----
impala-shell -V -k --ssl \
  -i pvcbase-worker2.cldrsetup.local:21050 \
  --var=scale=100 \
  -f scripts/compute-stats.sql
----

== Configure the Internal Query Runner
Update `util_internalRunQuery_impala.sh` with the correct Impala coordinator endpoint.

=== Option A — CDP Base Cluster
[source,bash]
----
sed -i 's/-i [^ ]*/-i pvcbase-worker2.cldrsetup.local:21050/' util_internalRunQuery_impala.sh
----

=== Option B — Impala Virtual Warehouse (Data Services)
[source,bash]
----
sed -i 's|impala-shell .*|impala-shell --protocol=hs2-http --ssl -i coordinator-ntnx-impala-vw.apps.cldrsetup.local:443 -s hive -k --kerberos_host_fqdn=dwx-env-cdp-env-1.cdp.local -d ${INTERNAL_DATABASE} -f "${INTERNAL_QUERYPATH}" \&>> "${INTERNAL_LOG_PATH}"|' util_internalRunQuery_impala.sh
----

== Run TPC-DS Queries
Execute the full suite of TPC-DS queries using the `query_runner.sh` script:

[source,bash]
----
nohup sh query_runner.sh 100 parquet > tpcds_100_log &
tail -f tpcds_100_log
----

== View Query Execution Results
After the benchmark completes, the results are captured in a CSV file titled `time_elapsed_tpcds<timestamp>.csv`.

=== Display Results
Use `cat` to view the raw execution times and success status:

[source,bash]
----
cat time_elapsed_tpcds*.csv
----

=== Sort and Format Results
To view the results in numerical order with the header intact:

[source,bash]
----
(head -1 time_elapsed_tpcds*.csv; tail -n +2 time_elapsed_tpcds*.csv | sort -V)
----

== Quick Reference Summary

| Step | Script / Command | Purpose

| 4 | `compute-stats.sql` | Enable efficient query planning
